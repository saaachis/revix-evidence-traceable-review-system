40 # ---------- api ---------- 

41 api_env: Literal["development", "production"] = "development" 

42 # Both loopback spellings, because a browser treats "localhost" and 

43 # "127.0.0.1" as separate origins and the dev stack uses them 

44 # interchangeably. Missing one blocks the type-ahead in the browser while 

45 # the server still logs a healthy 200, which is a miserable thing to debug.

48 # Requests per minute per client address. Generous on purpose: the browse 

49 # page fires a handful of calls on load and a type-ahead fires one per 

50 # keystroke, so a real person can reach thirty in a burst without doing 

51 # anything unusual. This is a ceiling on abuse, not a throttle on use. 

52 rate_limit_per_minute: int = 120 

53 # Off by default in tests and local work, where the client is one machine 

54 # and a limit would only ever fire on ourselves. 

55 rate_limit_enabled: bool = True 

56 

57 # How long a raw payload is kept before the retention sweep drops it. 

58 # 

59 # The raw store exists so a parser can be improved and evidence re-derived 

60 # without contacting the source again, which is better engineering and 

61 # also the polite thing to do. Keeping it forever is what filled a 512 MB 

62 # database and stopped the pipeline for three nights, because every 

63 # nightly run stores every page and every comment thread it fetched, 

64 # unchanged text deduplicates by hash but a page that gained one comment 

65 # does not. 

66 # 

67 # Two weeks is chosen to cover the loop we actually use it for: notice a 

68 # parser is wrong, fix it, replay. Anything older than that has never once 

69 # been replayed, and the evidence derived from it is kept regardless. What 

70 # we give up is replaying a parser change against payloads from a month 

71 # ago, which we would rather lose than lose the pipeline. 

72 raw_retention_days: int = 14 

73 

74 # A ceiling in megabytes, because megabytes are what the limit is actually 

75 # denominated in and days are only a proxy for them. 

76 # 

77 # The first version of this policy had the age window alone, and it freed 

78 # nothing: every payload was inside the window, so the sweep ran, reported 

79 # "nothing past the window", and the migration behind it died on a full 

80 # disk exactly as before. An age window bounds how old the store gets. It 

81 # does not bound how big it gets, and size was the thing that broke. 

82 # 

83 # 120 MB of a 512 MB tier leaves the evidence, the verdicts and their 

84 # citations the room they need; those come to about 70 MB today. Oldest 

85 # payloads go first once the budget is passed, so the policy holds whatever 

86 # the run rate turns out to be. 

87 raw_max_megabytes: int = 120 

88

143 # ---------- model-level evidence ---------- 

144 # A review of "the Creta" is real evidence about a Creta SX(O) Turbo DCT, 

145 # but weaker evidence than a review of that exact trim. This is the 

146 # discount applied to it. 

147 # 

148 # 0.6 is a judgement, not a measurement, and it is here rather than inside 

149 # the fusion code so that it is visible, tunable, and obviously a choice 

150 # somebody made. It applies identically to every strategy, so it cannot 

151 # flatter one of them in the section 18.1 comparison. Setting it to 0 

152 # restores the old behaviour of ignoring model-level evidence entirely. 

153 model_level_evidence_weight: float = 0.6 

154 

155 # ---------- evidence floor ---------- 

156 # A verdict is suppressed below these thresholds rather than published badly. 

157 min_evidence_units: int = 40 

158 # Two, not three. Three was chosen before we knew what the Indian review 

159 # landscape actually permits, and it turned out to be a number about a 

160 # market we had not surveyed yet. For two-wheelers there are only two 

161 # publishers that allow us at all: ZigWheels forbids review paths, 

162 # 91wheels is Disallow: / outright, BikeWale exposes one review per model. 

163 # Holding out for a third meant every one of the fifteen bikes in the 

164 # catalogue published nothing. 

165 # 

166 # Two genuinely independent platforms is a real guard against one 

167 # platform's culture dominating a verdict, which is what this floor is 

168 # for. One is not. And the verdict page prints the source count, so a 

169 # reader can weigh a two-source verdict for themselves rather than taking 

170 # our word for it. See ADR 0009. 

171 min_distinct_sources: int = 2
